# Mãos que Ajudam

Projeto acadêmico de desenvolvimento Front-end criado durante a disciplina de Desenvolvimento Front-end.

## Apresentação do projeto

O Mãos que Ajudam é uma aplicação web acadêmica desenvolvida para representar uma ONG fictícia.

O projeto apresenta informações sobre ações sociais, projetos e formas de participação, além de disponibilizar um formulário de cadastro para pessoas interessadas em contribuir com a organização.

## Tecnologias utilizadas

O projeto utiliza as seguintes tecnologias:

- HTML5 para estruturação das páginas;
- CSS3 para estilização e responsividade;
- JavaScript para interatividade e manipulação do DOM;
- LocalStorage para armazenamento de dados no navegador;
- Git para controle de versão;
- GitHub para hospedagem e gerenciamento do repositório.

## Estrutura do projeto

Os arquivos estão organizados em pastas de acordo com suas funções:

- `html/` - páginas HTML da aplicação;
- `css/` - arquivos de estilização;
- `js/` - scripts JavaScript;
- `imagens/` - imagens utilizadas no projeto.

Principais páginas:

- `index.html` - página inicial;
- `projetos.html` - apresentação dos projetos e ações;
- `cadastro.html` - formulário de cadastro.

## Funcionalidades

Entre as funcionalidades implementadas estão:

- navegação entre as páginas;
- apresentação dinâmica de projetos;
- formulário de cadastro;
- validação dos campos do formulário;
- máscaras para CPF, telefone e CEP;
- mensagens de sucesso e erro;
- armazenamento e recuperação de dados com LocalStorage;
- notificações e elementos interativos;
- melhorias de acessibilidade no formulário.

## Como executar o projeto

Para obter o projeto pelo GitHub, clone o repositório utilizando Git:

```bash
git clone https://github.com/Bosyah/maos-que-ajudam.git
```

Depois, acesse a pasta do projeto:

```bash
cd maos-que-ajudam
```

Por utilizar HTML, CSS e JavaScript, o projeto não necessita da instalação de dependências adicionais.

Para executar a aplicação, utilize um servidor local e abra as páginas pelo navegador.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão.

Durante o desenvolvimento foram utilizados:

- commits para registrar as alterações realizadas;
- branches para desenvolver alterações separadamente;
- issues para registrar tarefas e melhorias;
- pull requests para revisar e integrar alterações à branch principal (`main`).

Esse fluxo permite manter um histórico organizado das alterações realizadas durante o desenvolvimento.
